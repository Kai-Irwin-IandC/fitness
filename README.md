# Kai Health 健康管理

体重・睡眠・食事・筋トレの 4 つのゴールを 1 画面で管理する個人用 Web アプリ。
iPhone ではホーム画面に追加してアプリとして、PC ではブラウザで使う。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 4 つのゴールの達成状況、今日の PFC、睡眠日誌（前日の値を入力済み）、夜の 3 行まとめと「明日やること」 |
| 体重 | 大きな入力欄と ±0.1 ボタンで記録（過去の日付も可）、毎朝の体重と 7 日平均のグラフ、日ごとの記録と前日比 |
| 食事 | テンプレート（時短・安い・高たんぱく低脂質の 12 品）を「食べた」ボタン 1 つで記録。今の時間帯・残りカロリーに合う順に並ぶ。P・F・C の数字入力も可。目標に対するバランスを表示 |
| ジム | 分割法のテンプレート（Push/Pull/Legs・上半身/下半身・全身・部位別 5 分割）で「次の日」を表示。部位別（胸・背中・肩・脚・腕・腹）に約 50 種目。前回の記録から今日の目標を入力済みにし、1 タップで 1 セット記録、休憩タイマー。「ベンチ 80 8×3」の短文でも記録 |
| 推移 | 種目ごとの推定 1RM（自重は最高回数）、睡眠時間と睡眠効率 |
| 設定 | 身長・体重・目標・活動量、種目（部位・器具・上げ幅）、同期のパスコード、バックアップの書き出し／読み込み |

カロリー目標は「消費カロリー − 目標ペースに必要な不足分」から始め、毎週月曜に先週の 7 日平均の実際の減り方と予定を比べて ±200kcal の範囲で自動調整する。
PFC の目標は、たんぱく質 = 体重 × 設定値（g/kg）、脂質 = カロリーの 25%、炭水化物 = 残り。

## データ

DB は使わない。記録はまず端末のブラウザ（localStorage）に保存し、Vercel Blob の非公開ファイル 1 つ（`kai-health/data.json`）と同期する。

- 記録するたびに 1.5 秒後に送信し、アプリを開いたとき・画面に戻ったときに取り込む
- オフラインでも端末には保存され、つながったら送る
- 2 台で同時に記録したときは両方の記録を残して合わせる（その間に片方で消した記録は戻ることがある）
- Blob の読み書きにはパスコード（`APP_PASSCODE`）が必要。設定画面で端末ごとに一度入れる
- Blob を設定しなくても、その端末だけで使える

## ローカルで動かす

```bash
npm install
npm run dev
```

同期も試すときは `vercel env pull .env.local` などで `BLOB_READ_WRITE_TOKEN` と `APP_PASSCODE` を入れる。

## Vercel にデプロイ

1. Vercel で この GitHub repo を Import する（Framework: Next.js、設定はそのまま）。
2. プロジェクトの Storage → Create → Blob でストアを作り、このプロジェクトに Connect する（`BLOB_READ_WRITE_TOKEN` が自動で入る）。
3. Settings → Environment Variables に `APP_PASSCODE`（自分で決めた長めの文字列）を追加し、Redeploy。
4. iPhone の Safari でデプロイ先を開き、共有 → 「ホーム画面に追加」。設定 → 同期 にパスコードを入れる。PC でも同じパスコードを入れる。

## 構成

- Next.js 15（App Router）+ Tailwind CSS 4、Irwin&co 標準の App Shell（PC はサイドバー、iPhone は下のタブバー）
- `lib/calc.ts` — 7 日平均、カロリー・PFC 目標と週ごとの調整、睡眠効率、次の目標重量、分割法の次の日、推定 1RM、1 日のまとめ
- `lib/exercises.ts` — 種目ライブラリ（部位・器具）と分割法テンプレート
- `lib/store.ts` — localStorage の読み書き、古い保存形式の自動変換、バックアップ
- `lib/sync.ts` / `app/api/sync/route.ts` — Vercel Blob（private）との同期（ETag で上書き事故を防ぎ、競合時はマージ）
- `lib/meal-templates.ts` — 食事テンプレート（材料ごとの栄養と値段から合計を計算）
